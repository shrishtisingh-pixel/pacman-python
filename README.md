# Pac-Man in Python

A beginner-friendly Pac-Man clone built with Python and Pygame.

## Features
- BFS (Breadth-First Search) ghost AI: red and pink ghosts take the shortest path
- Random-walk AI for the orange ghost and scared ghosts
- Screen-wrapping tunnel
- Generated sound effects (no audio files needed)
- Saved high score

## Run it
```
pip install -r requirements.txt
python pacman.py
```

## Controls
| Key | Action |
|---|---|
| Arrow keys / WASD | Move |
| P | Pause |
| M | Mute |
| R | Restart |
| Esc | Quit |
